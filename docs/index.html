An intelligent parser for Abaqus .inp files

Parse your FEA models.

FileFold reads a large .inp file block by block and understands what each keyword is. Then it splits the file by category (*MESH, *MATERIAL, *STEP and more), or all the way down to one file per material, step or part. Track your edits, spot conflicts, and reimport an updated model without losing your changes.

Open FileFold Download for Mac / Windows

The web app runs entirely in your browser. Your model is never uploaded, and nothing needs installing.

03

Features

Built for people who maintain real models.
Split depth
Split as deep as you need. Stop at whole categories, or go further: one file per material, step or part; nodes, elements and sets; contact pairs and interactions; ties, couplings and rigid bodies. You only see options that will actually produce a file.
Round trip
Byte-exact. The reassembled model is character-for-character identical to the original: same lines, same line endings, no reformatting.
Change tracking
Hash-based change detection. SHA-256 tracks every file. Reimport knows whether a child changed in the new source, was edited by you, or both, and flags the conflicts.
Editor
In-browser file editor. Find, line-range selection, comment toggling, and a save / discard prompt when you leave with unsaved edits.
Parser
Container-aware parsing. Understands *PART, *STEP and *ASSEMBLY nesting and wrapped keyword lines. Material and contact options travel with their parent and are never split apart.
Privacy
Private by design. The web app runs entirely in your browser: your model is never uploaded and workspaces stay on your device. Decks up to 100 MB are tested; use the desktop app or command line for larger ones.
Export
Export as ZIP. Download the mother file and every child as one archive, ready for submission or archiving.
Desktop
Native desktop app. Runs locally on Mac and Windows from the system tray, with no internet needed.
Guidance
Sample data and a skippable tour. Three real decks to try, a one-minute tour of creating a workspace, small (i) reminders where they help, and an Info page describing every function. Light and dark themes.
Command line
Command line included. Everything the app does is scriptable: inspect, split, create workspaces, re-split, recombine, reimport and export. The same workspaces open in the app.
04

Supported

The full breakdown of what FileFold reads, splits and runs on.

Keywords and categories

FileFold recognises 523 keywords, every one in the Abaqus 2016 Keywords Reference, plus about 60 newer ones named in the 2026 release notes. Each belongs to one of eleven categories, and nine of them can be extracted.

mesh
*NODE, *ELEMENT, *NSET, *ELSET, *SURFACE and *PART blocks, with their generators.
section
*SOLID SECTION, *SHELL SECTION, *BEAM SECTION, *ORIENTATION, *CONNECTOR SECTION.
material
*MATERIAL with all its options: *ELASTIC, *PLASTIC, *DENSITY, *HYPERELASTIC, *DAMAGE INITIATION, *USER MATERIAL.
step
*STEP and everything inside it: *STATIC, *DYNAMIC, *FREQUENCY, *BUCKLE, *HEAT TRANSFER. A step moves as one unit.
loads
Loads and conditions outside steps: *BOUNDARY, *CLOAD, *DLOAD, *DSLOAD, *AMPLITUDE, *TEMPERATURE.
contact
*CONTACT PAIR, general *CONTACT, *SURFACE INTERACTION, *FRICTION, *SURFACE BEHAVIOR.
constraint
*TIE, *COUPLING, *MPC, *EQUATION, *RIGID BODY.
initial
The starting state: *INITIAL CONDITIONS.
output
*OUTPUT, *NODE OUTPUT, *ELEMENT OUTPUT, *RESTART, *NODE PRINT and the other output requests.
model
Model set-up: *HEADING, *PREPRINT, *INCLUDE, *ASSEMBLY, *INSTANCE. Stays in the mother file.
unknown
Keywords FileFold does not recognise. They stay with the keyword above them and are never separated from it.

Finer splits

A ticked category can split further. You are only offered splits that would produce a file for your deck. Alternatives for the same blocks, such as a whole part or just its nodes, cannot both be ticked.

mesh
Nodes, elements (or one file per element type), node sets, element sets, surfaces, or one file per part.
material
One file per material, each with its options.
step
One file per step, named after the step.
contact
Contact pairs, interaction properties, general contact.
constraint
Ties, couplings, rigid bodies, MPCs and equations.
loads
Boundary conditions, amplitudes, applied loads, thermal.

What the parser understands

Line types
* keyword lines, ** comments, data lines and blank lines. Everything after a keyword, up to the next keyword, belongs to it.
Wrapped lines
A keyword line ending in a comma continues on the next line; its parameters are merged. Quoted values may contain commas.
Case and spacing
Keywords are matched whatever the case and spacing. Your own text is never reformatted.
Options
Options always stay with their parent: *ELASTIC with its *MATERIAL, *FRICTION with its *SURFACE INTERACTION.
Containers
*PART, *ASSEMBLY, *INSTANCE and *STEP own the blocks inside them, which travel with the container.
Line endings
Windows (CRLF) and Unix (LF) files keep their line endings through every split, edit and recombine. The reassembled model is byte-identical.
Existing includes
An *INCLUDE already in your file is kept exactly as written.

What you can do with a workspace

Create
Upload or load a sample, tick categories and finer splits, name it. Nothing happens until you press Create workspace.
Extract and split
Extract more categories later, split a category further, or change which finer splits exist, from the Splits tab.
Fold back and rename
Fold any file back into its parent, rename files (the *INCLUDE lines follow), rename or delete whole workspaces.
Edit
Edit any file in the built-in editor: find, line-range selection, comment toggling, save and discard. Changed files are marked edited.
Reimport
Bring in a newer version of the model. Each file is marked safe to update, unchanged or conflict, you choose what to overwrite, and you can extract categories that are new.
Export
Download a ZIP of the mother file and every child.
Command line
filefold inspect, filefold options, filefold split, filefold split-partial, filefold serve, filefold launch, and filefold workspace list, create, status, options, extract, resplit, recombine, rename-file, rename, delete, export, cat, put, reimport.
Learn
Sample decks Job-1, mmxmn and fempy_example, a skippable tour, (i) reminders, and an Info page.

Where it runs

Browser
Runs entirely in your browser (Python compiled to WebAssembly). Nothing is uploaded; workspaces are kept in this browser. Decks up to 100 MB are tested (about 7 seconds to inspect, 15 to create); larger ones may run out of memory.
macOS
Menu-bar app with a local server. Files stay on your machine.
Windows
Tray app with a local server. Files stay on your machine.
Command line
Python 3.13 and uv. Everything the app does, on the same workspaces, and the way to handle very large decks.
Self-hosted
A Docker image and FastAPI server are included. Optional shared password and upload size limit. One shared workspace folder and no accounts yet.

Not supported yet

Other formats
Only Abaqus .inp text files. No .odb, .cae or .sim.
Running analyses
FileFold organises input files. It does not run Abaqus or check that a model will solve.
Existing includes
Files that your own *INCLUDE lines point to are not opened or split.
Inside a step
A step moves as one unit; there is no finer split within it.
Accounts and sharing
No sign-in and no shared team workspaces yet.
Phones
The app is built for desktop and tablet screens.
