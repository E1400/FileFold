How it works

One file in. Organized workspace out.

01

Upload mother file

Drop your .inp — FileFold parses every keyword block and maps the full structure.

02

Choose categories

Pick which top-level blocks to extract. Nested sections stay with their container — no misclassification.

03

Get a workspace

Each category becomes its own file. The mother file gets *INCLUDE pointers — Abaqus reads it identically.

04

Edit and reimport

Edit child files freely. When the source updates, reimport it — conflict detection shows exactly what changed.

Features

Built for engineers who
maintain real models.

Byte-exact round-trips

The reassembled model is character-for-character identical to the original. No reformatting, no silent changes to your data lines.

Hash-based change detection

SHA-256 tracks every file. Reimport knows whether a child changed in the new source, was manually edited, or both — and flags conflicts.

In-browser file editor

View and edit any workspace file directly in the UI. Tab indenting, unsaved-changes guard, Cmd+S to save.

Container-aware parsing

Understands *PART, *STEP, *ASSEMBLY nesting. Blocks nested inside a container follow the container — never split incorrectly.

Export as ZIP

Download your complete workspace — mother file plus all children — as a single archive ready for submission or archiving.

Native desktop app

Runs locally on Mac and Windows — system tray icon, no internet needed, files never leave your machine.
