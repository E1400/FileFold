Workspaces

The idea

One big .inp in. A small mother file plus child files out. The mother pulls its children back in with *INCLUDE, so Abaqus reads the model exactly as before.

*INCLUDE, INPUT=mesh.inp

Upload and inspect

Drop a .inp, or load a sample below. The block inspector lists every keyword block, coloured by category: mesh, material, step, loads, contact and more. Options always stay with the keyword they belong to.

Choose what to extract

Tick the categories you want in their own files. Model set-up such as *HEADING and *ASSEMBLY stays in the mother. Nothing is created until you press Create workspace.

Go deeper

A category can split further: one file per material, step or part; nodes, elements and sets; contact pairs and interaction properties; ties, couplings and rigid bodies. You only see options that will really make a file. Some are alternatives (a whole part or just its nodes): the one you tick first wins and the other greys out.

Edit freely

Open any file in the editor. Ctrl/Cmd+S saves, Ctrl/Cmd+F finds, Ctrl/Cmd+G selects a line range, Ctrl/Cmd+/ comments a block. FileFold remembers what it wrote, so a changed file shows an edited badge. Windows or Unix line endings are kept as they were.

Re-split any time

The Splits tab lets you change your mind: extract more categories, split further, fold files back into their parent, rename files. Lines are never lost or duplicated, so the pieces always add up to the original model.

Reimport a new version

An updated .inp arrived? Reimport it. Each child is marked safe to update, unchanged, or conflict (changed upstream and edited by you). You decide what gets overwritten.

Take it with you

Export ZIP gives the mother plus all its children. The same workspaces can be scripted with the filefold command line. Your files are kept in this browser, on this device. Nothing is uploaded anywhere. on the server, in this app's workspace folder.

New here? and follow along. It is small enough to try everything in seconds.

Sample data Real decks to try every feature on. Loading one starts a new workspace; the sample itself is never changed.
